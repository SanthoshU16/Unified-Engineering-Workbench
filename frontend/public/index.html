Bring-up sequence & simulator limitsPractical checks before connecting a physical target⌄

Bring-up sequence

  1. Confirm the exact board revision, connector orientation, pinout, and permitted power source from its manufacturer documentation.
  2. Keep target power independent from the debug probe. Verify regulated rails and the intended ground reference before attaching signal cables.
  3. Match each interface to its voltage domain. Use a translator rated for the bus direction, speed, and target I/O; verify the probe reads a valid target VTREF.
  4. Use the correct MCU SWD or FPGA JTAG cable. Check pin one and signal ownership before powering the target or starting a debug session.
  5. Bring up one link at a time, confirm discovery and a plausible telemetry response, then test recovery with a controlled timeout.

What this prototype does not validate

Adapters are deterministic C++ mocks. The page does not enumerate USB hardware, measure signal integrity, enforce real electrical limits, run firmware, or program an FPGA. Treat the diagram as a reference architecture, not a wiring drawing. Verify every connection against the documentation for the exact board and probe before physical integration.
